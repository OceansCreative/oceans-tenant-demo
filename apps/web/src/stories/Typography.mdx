# タイポグラフィ

OceansTenant の UI は **Noto Sans JP** を主役に、`next/font/google` で self-host しています。
未定義時のフォールバックは `system-ui` → `-apple-system` → `Segoe UI` → `sans-serif` の順で、
Storybook 環境では `next/font` の CSS 変数が注入されないため `system-ui` が描画されます。

font 設定の単一ソースは `apps/web/src/styles/globals.css` の `@theme` ブロックです。

```css
--font-sans:
  var(--font-noto-sans-jp), "Noto Sans JP", system-ui, -apple-system, "Segoe UI", sans-serif;
```

## グローバル設定

- `body` の `line-height: 1.7`（日本語可読性のためのややゆとりがあるベース）
- `::selection` 背景は `var(--color-brand-100)`（後述 Colors を参照）
- `:focus-visible` は brand-500 の 2px outline + offset 2px
