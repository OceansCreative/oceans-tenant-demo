# デザイントークン

カラー以外の基礎トークン（角丸 / 影 / フォントウェイト / 余白スケール）をまとめます。
個別の独自トークンは増やさず、原則として Tailwind v4 の既定スケールを採用します。

    <p className="text-xs font-medium">rounded-sm · 2px</p>
  </div>
  <div className="flex flex-col items-center gap-2">
    <div className="h-16 w-16 rounded-md bg-brand-100" />

  </div>
  <div className="flex flex-col items-center gap-2">
    <div className="h-16 w-16 rounded-xl bg-brand-100" />

  <div className="flex flex-col items-center gap-2">

## 共通レイアウト

- ページコンテナ: `container-page` ユーティリティ（`mx-auto w-full max-w-7xl px-4 sm:px-6 lg:px-8`）
- 物件カード幅: `max-w-[360px]` 〜 grid 内で `auto`、画像は `aspect-[4/3]`
- 地図ビュー: `h-[520px]` 程度を維持して CLS を抑制
