# カラーパレット

OceansTenant のブランドカラーは **OKLCH** 色空間で定義された青系のスケールです。
Tailwind v4 の `@theme` ブロックでカスタムプロパティとして定義され、
`bg-brand-500` / `text-brand-700` のようにユーティリティ経由で参照します。

色定義の単一ソースは `apps/web/src/styles/globals.css` です。

主要な使い分け:

- `brand-50` / `brand-100`: ハイライト背景・選択中 chip・hover 背景
- `brand-500`: focus-visible outline、リンク・アクセント
- `brand-600`: 主要ボタン背景（送信 / 適用）、`text-white` と組み合わせる
- `brand-700`: 主要テキスト強調 / hover 後の濃いボタン
- `brand-900`: ロゴ・極めて濃いテキスト・暗背景

## コントラスト方針

- 本文（`text-neutral-900` on white）と補助（`text-neutral-500` on white）はいずれも WCAG AA 以上を満たします
- focus-visible は brand-500 outline で a11y 上の可視性を担保します
- 詳細な a11y チェックは `@storybook/addon-a11y` パネルおよび CI の axe-core テストで継続検証します
